# Project Requirements

## Project Name

Retail Demand Forecasting & Inventory Optimization

## Problem Statement

Retail businesses need to estimate future product demand to maintain sufficient inventory while avoiding unnecessary overstock.

This project aims to use historical retail sales data and related business information to forecast future demand and support inventory planning.

## Functional Requirements

- Load and analyze retail sales data.
- Clean and transform the raw datasets.
- Store analytical data in a cloud data warehouse.
- Build data transformation models using dbt.
- Create demand forecasting models.
- Evaluate forecasting performance.
- Calculate inventory-related metrics.
- Provide what-if analysis for pricing scenarios.
- Present results through an interactive dashboard.

## Data Requirements

The project will use the M5 Forecasting Dataset.

Important data includes:

- Historical daily sales
- Product information
- Store information
- Category and department information
- Calendar information
- Events
- Product prices

## Technology Requirements

- Python
- SQL
- Google BigQuery
- dbt
- Prophet
- LightGBM
- Streamlit

## Expected Outputs

- Clean analytical dataset
- Forecasting models
- Forecast evaluation results
- Inventory recommendations
- Interactive dashboard
- Project documentation
